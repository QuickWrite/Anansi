# Anansi
A mischievous web application that returns the caller a collection of text that is generated using a Markov chain.

## Usage

```cmd
$ ./Anansi
2026/04/30 12:42:42 Running Anansi
```

The program will now run on the port `8080` and will accept any HTTP request.
