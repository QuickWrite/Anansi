# Anansi
A mischievous web application to generate an endless stream of senseless text.
The text is being generated by a [Markov Chain](https://en.wikipedia.org/wiki/Markov_chain) where it's weights are set using a starting text.

## Usage

```cmd
$ ./Anansi path/to/file
2026/04/30 12:42:42 Running Anansi
```

The program will now run on the port `8080` and will accept any HTTP request with a path that contains information.
